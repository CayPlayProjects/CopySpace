# CopySpace 0.4.3

**Your Personal Clipboard** - локальная библиотека истории буфера обмена для Windows на Python и PySide6.

CopySpace сохраняет скопированный текст, ссылки и изображения в отдельную локальную коллекцию. В приложении есть поиск, категории, избранное, закрепление записей, предварительный просмотр и несколько светлых и тёмных тем.

## Возможности

- Локальная история скопированного текста и растровых изображений.
- Автоматический захват буфера обмена по переключателю; при первом запуске захват выключен.
- Ручное сохранение текущего содержимого кнопкой **«Сохранить сейчас»** или сочетанием `Ctrl+Shift+V`.
- Распознавание ссылок и отдельный раздел «Ссылки».
- Импорт PNG, JPG/JPEG, BMP, GIF, TIFF и WEBP, в том числе файлов изображений, скопированных в Проводнике Windows.
- Поиск по содержимому и категориям (`Ctrl+F`).
- Категории, избранное и закрепление важных записей.
- Просмотр и копирование сохранённого текста или изображения обратно в буфер обмена.
- Фильтр «Без категории» для записей без пользовательской коллекции.
- Светлые и тёмные варианты цветовых схем: Фарфор, Лаванда, Океан, Мята, Роза и Сланец, а также тема Полночь.
- Локальная база SQLite и отдельная папка для изображений.
- История ограничена 800 элементами по умолчанию.
- Эвристический фильтр некоторых очевидных паролей, токенов, одноразовых кодов, приватных ключей и номеров платёжных карт.

## Установка и запуск в Windows

1. Установи Python 3.10 или новее с сайта https://www.python.org/downloads/windows/.
2. Во время установки включи **Add python.exe to PATH**.
3. После установки закрой и заново открой терминал или Проводник.
4. Распакуй архив в обычную папку, например `C:\CopySpace`.
5. Дважды нажми `run.bat`. Скрипт найдёт команду `python`, `python3` или `py`, создаст `.venv` и установит зависимости.

Для ручного запуска из PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe copyspace.py
```

Если Windows пишет, что `python` или `py` не является командой, установи Python с python.org, включив **Add python.exe to PATH**, затем открой новое окно терминала. Команда `py` не обязательна.

## Сборка EXE

На Windows с установленным Python запусти `build_exe.bat`. Сценарий создаст виртуальное окружение, установит зависимости и PyInstaller, а затем соберёт приложение.

Готовый файл появится здесь:

`dist\CopySpace\CopySpace.exe`

Для запуска на другом компьютере копируй **всю папку** `dist\CopySpace`, а не только EXE. Сборку нужно выполнять на Windows; готовый EXE в исходный ZIP не входит.

## Где хранятся данные

Новая папка данных: `%LOCALAPPDATA%\CopySpace\`.

В ней находятся `copyspace.db` (история, категории и настройки) и папка `images\` (сохранённые изображения).

### Перенос с ClipVault

При первом запуске CopySpace проверит наличие старой папки `%LOCALAPPDATA%\ClipVault\`. Если новая база CopySpace ещё не создана, приложение скопирует историю, настройки и изображения в новую папку, а базу переименует в `copyspace.db`. Исходная папка `ClipVault` **не удаляется** и остаётся резервной копией. Закрой старую версию ClipVault перед первым запуском CopySpace, чтобы база данных не менялась во время переноса.

Если папка CopySpace уже содержит собственную базу, она не будет заменена старой. В такой ситуации старая папка ClipVault останется на месте как отдельная резервная копия.

## Конфиденциальность и ограничения

- Данные остаются локально на компьютере: синхронизации или облачного хранилища нет.
- При первом запуске автоматический захват выключен. Включай его только когда понимаешь, что копируешь.
- Фильтр чувствительных данных основан на шаблонах и эвристиках. Он может пропускать секреты и иногда блокировать обычный текст. **Не используй CopySpace для хранения паролей, банковских данных, приватных ключей или другой конфиденциальной информации.**
- Захват работает, пока приложение запущено. Глобальное отслеживание при закрытом приложении не выполняется.
- Максимум текста - 1 МБ, изображений - 8 МБ и 16 мегапикселей.

## Горячие клавиши

- `Ctrl+F` - перейти к поиску;
- `Ctrl+Shift+V` - вручную сохранить текущее содержимое буфера обмена;
- `Delete` - удалить выбранную запись (с подтверждением).

## Структура проекта

- `copyspace.py` - интерфейс PySide6;
- `copyspace_core.py` - SQLite, хранение данных, классификация ссылок и фильтр очевидных секретов;
- `requirements.txt` - зависимости;
- `tests\test_copyspace.py` - тесты ядра и миграции;
- `run.bat` - запуск приложения;
- `build_exe.bat` - сборка EXE.

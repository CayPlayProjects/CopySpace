# CopySpace

**Your Personal Clipboard** - локальная библиотека истории буфера обмена для Windows на Python и PySide6.

CopySpace сохраняет скопированный текст, ссылки и изображения в локальную коллекцию. Приложение поддерживает поиск, категории, избранное, закрепление записей и светлые/тёмные темы.

## Возможности

- История скопированного текста, ссылок и изображений.
- Автоматический захват буфера обмена с возможностью включения и выключения.
- Ручное сохранение содержимого буфера: кнопка «Сохранить сейчас» или `Ctrl+Shift+V`.
- Распознавание ссылок и отдельная категория ссылок.
- Импорт PNG, JPG/JPEG, BMP, GIF, TIFF и WEBP, включая изображения, скопированные через Проводник Windows.
- Поиск по содержимому (`Ctrl+F`), категории, избранное и закреплённые записи.
- Предварительный просмотр и повторное копирование сохранённых элементов.
- Фильтр записей «Без категории».
- Несколько светлых и тёмных цветовых схем.
- Локальное хранение в SQLite; синхронизация с облаком не используется.

## Требования

- Windows 10/11
- Python 3.10 или новее
- PySide6 (устанавливается автоматически скриптом запуска)

## Быстрый запуск

1. Установите Python с [официального сайта](https://www.python.org/downloads/windows/) и включите опцию **Add python.exe to PATH**.
2. Скачайте или клонируйте репозиторий.
3. Запустите `run.bat` двойным щелчком.

Скрипт создаст виртуальное окружение `.venv`, установит зависимости из `requirements.txt` и запустит приложение.

### Ручная установка

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe copyspace.py
```

## Сборка EXE

На Windows запустите `build_exe.bat`. Результат сборки появится в `dist\CopySpace\CopySpace.exe`. Для переноса на другой компьютер копируйте всю папку `dist\CopySpace`, а не один EXE.

## Данные и конфиденциальность

Данные приложения хранятся локально в `%LOCALAPPDATA%\CopySpace\`: база `copyspace.db` и папка `images\`. Облачной синхронизации нет.

При первом запуске CopySpace может перенести старую базу ClipVault. Исходная папка ClipVault при этом сохраняется как резервная копия.

Фильтр чувствительных данных эвристический и не гарантирует обнаружение всех секретов. Не используйте приложение для хранения паролей, банковских данных, приватных ключей и другой конфиденциальной информации.

- `build_exe.bat` - сборка приложения в EXE.

- `readmy.md` - дополнительное описание проекта.

# История изменений CopySpace

## 0.4.3 — полное переименование
- Приложение, окно, логотип, исходные модули, BAT-сценарии и сборка EXE переименованы в CopySpace.
- При первом запуске данные копируются из старой папки `%LOCALAPPDATA%\ClipVault` в `%LOCALAPPDATA%\CopySpace`.
- История, настройки и изображения сохраняются; исходная папка ClipVault остаётся резервной копией.
- База данных переименовывается в `copyspace.db`, а пути сохранённых изображений обновляются для новой папки.

## 0.4.2 — надёжный импорт изображений
- Исправлен захват изображений, скопированных напрямую из приложений и снимков экрана.
- Добавлен импорт файлов PNG, JPG/JPEG, BMP, GIF, TIFF и WEBP, скопированных в Проводнике Windows.
- Добавлена поддержка дополнительных MIME-форматов изображений, включая форматы, которые публикуют некоторые приложения Windows.
- Добавлена короткая задержка перед автоматическим захватом, чтобы буфер успевал предоставить все доступные форматы.
- «Без категории» теперь доступна в фильтре коллекций, и записи без назначенной коллекции можно найти отдельно.
- Расширены тесты для изображений и фильтрации по категории.

## 0.4.1 — точное распознавание ссылок
- Исправлена ошибка, из-за которой любое одиночное слово могло распознаваться как URL.
- Адрес без протокола теперь должен содержать домен или IP-адрес; URL с явным http/https/ftp и корректные mailto-адреса поддерживаются.
- Несколько строк распознаются как ссылки только тогда, когда каждая строка является адресом.
- Смешанный текст с URL остаётся обычным текстом.
- При запуске автоматически исправляются старые записи, ошибочно помеченные ссылками.

## 0.3.0 — полная перестройка интерфейса
- Полностью удалена вертикальная боковая панель: приложение теперь использует широкую горизонтальную компоновку.
- Создана верхняя командная строка с логотипом, поиском, состоянием захвата и ручным сохранением.
- Навигация по основным разделам перенесена в горизонтальную панель.
- Пользовательские коллекции теперь выбираются через отдельный выпадающий фильтр.
- Добавлены обзорные карточки со статистикой библиотеки: всего записей, текст, изображения и объём хранения.
- Обновлена основная рабочая область: список записей и большая отдельная панель предпросмотра.
- Страница настроек скрывает обзорные карточки, чтобы освободить полезную площадь.
- Сохранены все функции CopySpace, существующая схема SQLite, папка локальных данных и сценарии запуска/сборки.
- Повышена минимальная версия проекта до 0.3.0.

## 0.2.0 — отдельная визуальная идентичность
- Создана собственная визуальная концепция цифрового архива, отличная от SmartFolder.
- Добавлены семь палитр: Фарфор, Полночь, Лаванда, Океан, Мята, Роза и Сланец.
- Обновлены карточки истории и панель предпросмотра.

## 0.1.1
- BAT-скрипты ищут Python через `python`, `python3` или `py`.
- Улучшены сообщения при отсутствии Python и ошибках сборки.

## 0.1.0
- Первая версия локального менеджера буфера обмена.
- История текста и изображений, поиск, избранное, закрепление и категории.
- Локальное хранение SQLite и эвристический фильтр некоторых очевидных секретов.

## 0.4.0 — Themes & link recognition
- Added dark counterparts for all light color palettes.
- Clipboard URLs are recognized as links and stored in the Links collection.
- Added a dedicated Links navigation filter.
- Added a backwards-compatible SQLite migration for the content_type field.
